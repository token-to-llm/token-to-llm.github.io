建议

对全书内容取舍与章节编排的意见。哪一章讲得太快、哪一处例子可以更实在，都欢迎直说。

勘误

公式、代码、图表与文字中的错误。请注明页码或章节号；已确认的勘误会汇总到勘误表。

疑问

学习路径、前置知识与课后习题上的困惑。若问题涉及某段推导，附上你的理解与卡住的地方，回复会更有针对性。

合作

课程共建、教材采用与批量订购、技术交流与讲座邀约。请说明单位、用途与大致时间安排。

GitHub Issue 代码与课件的问题更适合走公开渠道：在 代码仓库的 Issues 中提交，便于检索、跟踪与其他人参考。
