# 本书介绍

《大语言模型：训练、精调与对齐》面向高年级本科生、研究生与算法工程师，把大语言模型从**原理**讲到**工程实现**。

它结合北京大学首门系统讲授大语言模型的课程《大语言模型基础与对齐》的讲义，以及作者线上课程《手撕 LLM》的教学经验结集成书，由清华大学出版社出版。

## 这本书要解决什么问题

当答案已经唾手可得，稀缺的不再是信息，而是顺序与判断。

**提问的质量，取决于提问者已有的框架。** 章节顺序本身是一张知识依赖图——注意力机制为什么排在缩放定律之后，RLHF 为什么先要有策略梯度的铺垫。先沿着这张图走一遍，再向模型追问，问题的质量会完全不同。

**流畅的表达，不等于可复核的结论。** 模型的输出是概率性生成，写错的公式与写对的公式在语气上没有区别。教学、考核与工程实现都需要一份可以指出页码的底本：公式能从假设推到底，数字能溯源到原始论文，代码能在仓库里跑起来。

**讲透需要篇幅，理解发生在摩擦里。** 问模型“RMSNorm 与 LayerNorm 有什么区别”，多半得到“更快、更稳定”这一句。它不算错，却跳过了快在哪里、稳定从何而来、代价又是什么——本书为它给了四页、三层推导和一组实测数字。

所以这本书并不打算与模型竞争，而是给模型一个可以对照的底本：**模型负责即时，教材负责可靠**。

## 知识体系

全书围绕三个维度展开，对应到训练流程的三个阶段：

| 维度 | 回答的问题 | 涉及内容 |
| --- | --- | --- |
| 学习范式 | 能力如何获得 | 自监督预训练、有监督微调、强化学习与对齐 |
| 模型与算法 | 模型如何构造 | 核心架构、训练目标及关键技术 |
| 系统实现 | 算法如何落地 | 结合模型特性与硬件条件的训练与推理方案 |

其中，强化学习是大模型对齐的关键机制。它把人的反馈引入训练，塑造模型的指令遵循与推理能力，并使模型从静态的文本生成器，逐步发展为能够感知反馈、作出决策并执行任务的智能体。**基于人类反馈的强化学习（RLHF）与可验证奖励强化学习（RLVR）两条路径，是本书着力梳理的重点。**

## 章节编排

全书十章，分四块递进：

- **第 1—4 章 · 基础与预训练**：从语言模型综述、缩放定律与涌现能力讲起，经注意力机制与 Transformer，落到 GPT、Llama 等解码器模型。
- **第 5—6 章 · 微调与应用**：有监督微调、参数高效微调、提示词工程、思维链、检索增强生成与智能体。
- **第 7—8 章 · 强化学习与对齐**：从经典强化学习出发，贯通 RLHF、DPO 与推理强化学习，是全书的重心。
- **第 9—10 章 · 训练与推理系统**：分布式训练与高效推理。

完整的节级目录见[章节指引](chapters.html)。

## 分层编排

为兼顾不同基础的读者，本书采用分层编排：

- **正文**集中讲解核心概念与主干方法；
- **关键算法**配有必要的推导与代码实现；
- **较深入的理论分析**放入带“*”标识的专题或附录。

初学者可以先跳过带“*”的专题，不影响对全书主线的理解；具备一定基础的读者则可以通过这些专题进一步探究算法背后的理论问题。第 1 章涉及的术语与概念较多，初次阅读时可以适当跳读，待完成后续章节后再行回顾。

## 本书内容

每个核心方法都尽量给出完整链条，读者可以对照公式、图示与代码逐步理解：

- **公式推导**：语言模型的目标函数、策略梯度、KL 正则等均给出完整推导，从假设到结论逐步展开。
- **算法代码**：缩放点积注意力、多头注意力等附完整 PyTorch 代码，便于对照公式运行与验证。
- **流程图**：RLHF 的 PPO 训练、奖励重塑等以流程图逐步展开，呈现完整的数据与梯度流向。
- **示意图**：RMSNorm 以三维散点图对比归一化前后的分布，Flash Attention 以分块更新与批量计算示意图说明在线 Softmax 的实现。

全书配有 **200+ 幅插图、20+ 个算法框、400+ 个编号公式与 337 篇参考文献**，以及 **900+ 页配套教学课件**。

## 适合谁读

- **在校大学生**：若感到课程内容与行业需求之间存在断层，本书可补齐其中缺失的一块。它不会代替完成作业，但能帮助你在面对“请解释一下 Multi-Head Attention 的计算复杂度”这类面试题时，给出有深度的回答。
- **AI 从业者**：若知识体系多来自碎片化阅读与项目经验，本书可帮助把散落的知识点串成体系，尤其是推理优化、分布式训练、模型部署这些实际工作中绕不开的环节。
- **高校教师**：可直接沿用本书的章节顺序作为教学进度，配套的 900+ 页课件与思考题省去了从零备课的成本，也便于按课时裁剪。

## 阅读建议

阅读前需要具备高等数学、概率论、线性代数与深度学习的基础。在此基础上：

1. 按正文顺序阅读，先跳过带“*”的专题；
2. 第 1 章术语与概念较为密集，可先粗读，待后续章节展开后再行回看；
3. 若以查阅为目的，可直接使用目录与附录提供的索引路径。
